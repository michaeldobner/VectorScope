| | |
|---|---|
| Zweck | Geprüfte OSINT- und Verteidigungsnachrichten, abgeglichen mit Flugzeugen, die gerade in der Luft sind |

| Quellen | 14, von Bluesky und RSS |
| Live-Daten | Militärflugzeuge von adsb.lol (ODbL), alle zwei Minuten |
